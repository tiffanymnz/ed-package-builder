# Developer Acceptance Scope — v58

This is a release gate, not a claim of perfect recognition or an optimal interface for every user. No known significant actionable defect identified in this pass is intentionally deferred to staff testing. A verified trial build requires a matching successful Windows run and inspected screenshots.

| Area | Developer checks |
|---|---|
| First-time entry | Create/Open actions, case/vendor first, import-first guidance, four workflow pages |
| Vendor intake | UI events continue, cancellable preparation, unchanged originals, exact duplicates, ZIP path safety, size limit, warnings, commit rollback |
| Documents | Image/PDF bids and invoices, unconfirmed import, page ranges, source-change rejection, scrollable short-window details, reachable confirmation |
| Photo review | 6/12/24 layouts, large paged galleries, selections and batch undo, original-source checks |
| Load cards | Live readings preserve edits, explicit suggested-stage choice, pending/reviewed queues, retry and changed-source handling |
| Reused containers | Container similarity stays separate from physical trips; insufficient or conflicting trip clues remain unresolved |
| Measurements | Visible source evidence, volume/fill/overage checks, calculation evidence and selected-load navigation |
| Costs | Invoice reconciliation, bid quantities/comparability, changed-source and financial-confirmation invalidation |
| Save/resume | Portable source-byte checks, path rebasing, cancellation, archive integrity, damaged optional-cache recovery |
| Interrupted workflow | Declined/cancelled export, save failure/cancellation and cancelled close resume current work |
| Repeated use | Refresh does not accumulate wheel handlers; destroyed scroll pages are removed |
| Package output | Complete and incomplete export behavior, original financial/photo inclusion, description validity, previous-output preservation and export recovery |
| Windows delivery | Full source suite, actual offline bundled inference, actual frozen imports/document UI, navigation, DOCX/PDF export, screenshots and artifact digest |

Recognition uncertainty caused by ambiguous evidence remains visible for review. The models and thresholds are unchanged in v57; the existing supplied-data measurements and limitations remain in RELEASE_VALIDATION.md. Company-device compatibility and real staff time saved are not measurable in this environment, and are not used to excuse known software defects.

The v58 gate adds selection without image reloads/grid rebuilds, preserved cross-page checks, explicit outside-filter scope, source-change rejection after fast selection, disabled no-case actions and readable measurement findings. Recognition models are unchanged.
