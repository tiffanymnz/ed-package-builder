# ED Package Builder

Prepare an Excessive Debris package from vendor documents and photos. Start with the case number and vendor, import files, review load evidence, check costs, and create the combined package.

- Accept invoice and bid images or PDFs.
- Review container measurements and loading stages in the package template.
- Use checked load cards and photo clues to organize evidence; filenames do not determine a stage or trip.
- Compare bids and reconcile the first-10-CYD HUD deduction at the request rate.
- Save Project to keep an editable `.edcase` file and reopen it later.

Read START_HERE.md for the workflow and INSTALL.txt for building the Windows portable app.
